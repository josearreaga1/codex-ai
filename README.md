# codex-ai

## Overview

This repository is set up for work on the `codex-ai` project.
Use this README as the starting point for project notes, setup instructions,
and feature-specific documentation as the codebase grows.

## Codex Project Config

Codex supports shared project configuration in `.codex/config.toml`.
Checking that file into the repository makes local environment setup and
common project actions available to everyone working in this repo.

Update `.codex/config.toml` as the project grows so the team's default
Codex workflow stays consistent.
